Prediction API Endpoint

Gunakan endpoint ini untuk integrasi aplikasi lain ke model prediksi diabetes.

Endpoint
POST/api/predict

Kirim JSON berisi 8 fitur original. Response berupa prediksi, probabilitas, risk category, risk factors, dan interpretasi.

  -d '{{ sample | tojson }}'
